# Brand strategy

**Prompt Chaining Studio · Proposed direction · November 12, 2026**

## Positioning

**Brand line**  
Make the next step better.

**One-sentence description**  
Prompt Chaining Studio is a local workbench and set of guided activities for learning to check AI answers, improve them, and carry useful work into the next step.

**Promise**  
See what carries forward, decide what belongs there, and keep a record you can return to.

**Proof**  
Classroom Challenges show the same words in an answer and in the next prompt. Learners revise a draft using clues and see their edit carried forward. In the Workbench, a saved run keeps the prompts, answers, and progress. A person can review a step, revise an answer at a review pause, and export the result or the trace. [Classroom walkthrough](../DEMOS.md#try-it-with-a-class) · [Saving and recovery](../SAVING-EXPORT-AND-RECOVERY.md)

**Purpose**  
Make a multi-step AI workflow understandable and interruptible. A person should be able to tell where an answer came from, change what happens next, and resume with less reconstruction.

## Audience and intent

| Audience | What they want to do | What to show first | What they need to know |
| --- | --- | --- | --- |
| Fifth-grade teachers and instructional coaches | Lead a specific AI literacy activity and hear students explain what changed | A class has to stay seated. The draft says to throw a paper ball. Which clue did it miss? | Run the activity from the teacher’s installed copy. The responses are prepared and the challenge makes no model requests. |
| Fifth-grade learners | Solve a problem, contribute an idea, and see it make a difference | Read the rule. Find the mistake. Give a fix in one sentence. | A prompt is what you ask AI to do. Several fixes can fit the clues. |
| Ryan and independent practitioners | Reduce repeat entry and return to a task after an interruption | Choose a recipe, review one answer, and save a stopping point. | Live work uses the configured OpenRouter model. Runs save to the local workspace. |
| Parents and caregivers | Make something together and talk through a small decision | A family drawing game, a four-panel comic, or a paper invention | An adult can lead the offline example. Live generation is a separate, configured workflow. |
| Technical evaluators | See how handoffs, state, and exports behave | A run trace, the documented boundaries, and the Python API | Refer to the implementation and verification scope. |

For public-facing material, open with a teacher-led demonstration. It shows the defining mechanism without provider setup or a live response. The Workbench remains the project's operating center for Ryan. A Workbench page can lead with dictation, a saved method, and a concrete stopping point. A child-facing prompt starts with the problem in front of the class.

## Message hierarchy

1. **Show the change.** Put a checked sentence next to the prompt that uses it. In Workbench material, show the saved checkpoint and the next action.
2. **Give the audience a task.** Choose a game that fits the rules. Read a draft against a source. Save an instruction you will want again.
3. **Say how this example runs.** Name prepared examples and live model calls near the action.
4. **Give one way in.** Offer a teacher guide or an authored example. Explain local setup before presenting a link that only works on a running copy.

## Story and character

- **Curious.** Offer an interesting decision. “The class photo is in five minutes. Where would you look first?”
- **Exact.** Show the constraint or the source. “The class must stay at their desks, and there’s no throwing.”
- **On the reader’s side.** Leave a manageable next move. “One sentence is enough.”
- **Calm about uncertainty.** “The orange scrap could be from a bookmark. What could we check next?”

The design should feel like a working notebook people can think with. On a classroom screen, the problem and correction carry the energy. For the Workbench, prioritize reading, quiet status, and a predictable return path. [Visual identity](VISUAL-IDENTITY.md) · [Voice and experience](VOICE-AND-EXPERIENCE.md)

## Scope of the offer

The proposed first public package is a teacher guide, a Rainy Recess example, and a link to reviewed local setup instructions. A small educator pilot can test whether the setup is manageable and whether students can explain a handoff. The Workbench can be shared in parallel through its authored walkthrough, with local storage and live request behavior explained where people need it. Outreach, distribution terms, and any public availability are decisions for Ryan. [Market and SWOT](MARKET-AND-SWOT.md) · [Launch plan](LAUNCH-PLAN.md)
