# Prompt Chaining Studio brand and marketing kit

**Proposed brand and campaign · November 12, 2026**

[Open the visual review](index.html) to see the identity and campaign in use. The review is a local HTML file. The guides and editable assets below live beside it.

**Make the next step better.** The brand gives a teacher one visible example of a correction carrying forward. It gives a Workbench user a recognizable way to keep a method, review a step, and resume. The proposal keeps **Prompt Chaining Studio** as the name, with **Classroom Challenges** and **Workbench** as paths into it.

## Use the package

1. Review the positioning and the Rainy Recess demonstration. Use the prepared teacher handout with the local app or run the paper activity.
2. If Ryan chooses to share the project, start with a teacher-led rehearsal. Use the pilot plan to record setup friction and whether students can explain what changed. Use the authored Moon walkthrough for a separate practitioner demonstration.
3. Before sharing a release, choose the destination and distribution terms, then verify the current build, copy, and claims against the release being shared.

The name, tagline, new identity, audience priority, activity timing, and pilot size are proposals. Current behavior is documented in the [project README](../../README.md) and [user guides](../README.md).
