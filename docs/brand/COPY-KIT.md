### Page copy

#### Can your class rescue rainy recess?

Paper basketball won the vote. There's one problem. The teacher says no throwing. Ask your class to pick a game that works at their desks, then see what happens when their idea goes into the next instruction.

**Try it on one shared screen.** Read the clues aloud. Have students make a pick and say which clue helped. Show the draft, choose a one-sentence fix together, and look for the same words in the next prompt.

**Compare two ideas.** Put your class's fix beside a prepared example. Ask which clue supports each one and whether both would work. You just used a prompt chain. One answer became part of the next instruction.

**What you need.** Start Studio on one computer you can project. The challenges use replies written ahead of time and run offline after installation. The classroom activity needs no model account or API key.

**Want another challenge?** Follow the clues to a missing stuffed tiger, or fix the directions for a paper bridge that needs to hold eight cubes.

### Page copy

#### Give your AI work a place to pick up.

When a task takes several prompts, it helps to see exactly what the next step will use. Choose a recipe for something you want to learn, write, or decide. Enter or dictate a topic. Edit the steps and review the next prompt before you send it.

**Start with an example.** Follow a four-step Moon explanation and open the prompts to see what moved forward. The walkthrough uses prepared answers and requires no provider key.

**Keep the parts worth repeating.** Save your starting instructions as a recipe. Return to a saved run, add a note about where you stopped, or export the final answer and its prompt history.

**Choose when to use a live model.** Studio saves recipes and runs on your computer. Live generation requires your own OpenRouter key and model settings. A live step sends its inputs and referenced earlier answers to OpenRouter and the selected provider. Provider charges can apply.

## Rainy Recess facilitator card

**Allow** · A proposed 10–15 minutes once the app is open.

**Have ready** · One projected browser, a local Studio installation, and a fresh Rainy Recess run. Students can answer out loud, point to a clue, or write a sentence.

**Purpose** · Spot a rule the draft missed and show exactly where the class's correction goes next.

| Time | Action and words to use |
| --- | --- |
| 2–3 minutes | From Home, choose **Try a classroom challenge**, then **Rescue rainy recess**. Read the clues aloud. “Which game would you pick? Tell a partner which clue helped you decide.” |
| 2 minutes | Choose **See what the AI noticed**. Read the **First answer** and **Next prompt**. “Find the same words in both boxes. What new job does the next prompt give the AI?” |
| 3–5 minutes | Choose **Read the draft**. “The draft says to toss a ball. What did the rule say? What would you tell the next step in one sentence?” Enter one class suggestion and select **Save my fix**. If needed, reopen the clues or hint. |
| 3–5 minutes | Read the saved words in the next prompt, then choose **See the example answer**. “What words did we put there? Which clue backs up our fix? How does the example handle that clue?” |

Use this sample fix in rehearsal. “Choose robot drawing because clue A says we must stay at our desks and can’t throw.” Keep the students’ own clue-backed options open. The final example is prepared ahead of time.

## Workbench walkthrough script

Proposed length · 60–90 seconds. Use the authored Moon example as the recording source.

1. Start on Home. “A long task can use a series of short prompts. Let’s follow one from start to finish.”
2. Open **Explore the Moon example** in **Keep exploring**. Pick an answer and open **Prompt that produced this answer** on the following step. “This prompt includes material from the previous answer. Here’s where the next step got it.”
3. Open **My library** and return to the Moon run. “Studio saved the run here. I can open it again and read the prompts with the answers.”
4. Point to **Download trace**. “You can take the trace with you when you need to show how the answer was made.”
5. End with “Try the Moon example before setting up a model. Its replies were written ahead of time.” If the recording includes the recipe editor, end on a prepared local draft and name OpenRouter setup as the step for live answers.

## Search and handoff notes

- Use distinct titles and descriptions for the two audiences. Classroom copy uses plain terms a teacher might search for, including **fifth-grade AI literacy activity**, **prompt chain**, and **teacher-led activity**. Workbench copy uses **local prompt chaining workbench**, **saved runs**, and **editable AI workflows**. These terms describe intent. Traffic and search rank are unmeasured.
- Use an activity diagram or the correction in context for the preview image. Set the social card caption to “A sample answer is corrected, and the same correction appears in the next prompt.” Include meaningful image alt text where the destination supports it. Put essential facts in the post or page text too.
- Make every button or link resolve to a real guide, repository release, or local action in the intended environment. Review titles and share previews at publishing time. Run setup and demo checks in the proposed host environment before assigning an availability date.
