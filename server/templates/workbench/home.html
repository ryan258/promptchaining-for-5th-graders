What’s a prompt chain?

A prompt is what you ask AI to do. In a chain, you use an answer in the next prompt.

First prompt
Name two things a dragon could bring to show-and-tell.
Answer
A tiny kite and a cracked eggshell.
Next prompt
A tiny kite and a cracked eggshell. Use both to start a story about the dragon.
